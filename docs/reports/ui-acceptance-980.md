## 修复

1. **统计页短暂并发失败。** React 重挂载或快速切换筛选会在前一个服务端读取尚未退出时触发 429，原页面永久停在英文错误。保留后端并发预算，客户端仅对 429 做最多两次短暂重试；新筛选取消旧重试，持续忙碌显示中文提示，其他错误不重试。记录浏览器截图和失败用例后修复，同一回归通过。
2. **冲突处理采用旧版本。** 原“查看最新保存版本”和“使用保存版本”可能仍指旧缓存。409 后自动读最新配置，保留草稿；若刷新失败，禁止采用旧缓存或旧 revision。模型回归先失败再通过，浏览器确认真实采用并发保存的新值。
