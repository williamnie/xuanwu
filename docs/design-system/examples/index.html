02 · 按钮（一律直角 32px 高）

浅主题主按钮为黑底白字，深主题为荧光绿底黑字；不加阴影、不加渐变。

03 · 状态 Pill（dot 是全系统唯一圆形元素之一）

mono 大写 + 同色 8% 底 + 1px 边；running 态仅小圆点脉冲。

running succeeded failed idle

04 · Tabs（通栏细线 + active 实底）

1px 细线分割，不做漂浮大胶囊。

05 · 侧边栏列表项

active = 主色浅底渐变 + 左侧 2px 色条。
