# Xuanwu Design System（前端设计规范）

本目录是 **整体项目唯一的前端视觉规范**。任何在本仓库中编写、修改前端 UI 的 Agent（Codex / Pi / 人工贡献者）都**必须先阅读并严格遵守**本目录中的规范。

## 目录结构

| 文件 | 作用 |
|---|---|
| `README.md` | 本文件，入口与使用方式 |
| `spec.md` | **设计规范正文**：设计原则、设计令牌（颜色/圆角/字体/字号/间距/阴影）、组件规范、动画规范、禁忌清单 |
| `tokens.css` | 可直接引入的设计令牌（CSS 变量），含浅色「简洁」与深色「极客」双主题 |
| `components.css` | 规范内全部标准组件的参考实现 |
| `examples/index.html` | 组件总览（厨房水槽页），浏览器直接打开即可预览 |
| `examples/chat.html` | 完整页面示例：对话工作台 |
| `$xuanwu-ui` | 全局个人 Skill，只有显式调用时才加载；详细规范仍以本目录为项目内权威来源 |

## Codex 使用方式

本仓库的 `AGENTS.md` 已要求所有前端任务先读取本目录。需要主动启用全局 Skill 时使用：

> `$xuanwu-ui 按玄武设计规范实现或改造当前前端，并完成明暗主题与响应式验收。`

全局 Skill 默认关闭隐式调用，不会把玄武风格自动应用到其他项目。

## 速查

- 改样式前：查 `tokens.css` 有没有现成变量 → 查 `components.css` 有没有现成组件 → 都没有才新增，并回写进这两个文件。
- 浏览器打开 `examples/index.html` 可一键切换明暗主题对照全部组件。

## 一句话原则

> **方形几何 · 等宽微标签 · 单点荧光强调 · 细线分割而非色块堆叠 · 克制且一致的动效。**

任何「大圆角、大阴影、大面积彩色色块、渐变花哨按钮」的设计在本仓库**一律不接受**。
