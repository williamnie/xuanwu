# Xuanwu v0.2.3

玄武 `v0.2.3` 聚焦工作台与 Provider 对话体验，并加强 Web、Core 和 Agentic 运行时之间的
连接恢复、性能观测与发布诊断。

Xuanwu `v0.2.3` refreshes the workbench and provider chat experience while improving connection
recovery, performance visibility, and release diagnostics across the Web, Core, and Agentic
runtime roles.

## 重点更新 / Highlights

- **实时工作台 / Live workbench**：Work 与 Runs 页面每五秒静默同步最新状态，同时保留筛选、
  分页和当前交互状态。
- **玄武对话 / Xuanwu chat**：Supervisor 对话进入应用侧栏，完整 Provider 消息时间线得到恢复，
  内部执行过程默认折叠，输入区与会话布局保持一致。
- **连接恢复 / Connection recovery**：SSE 声明有界重试并禁止代理缓冲；前端通过独立探测区分
  reconnecting 与 offline，减少短暂断连造成的错误离线提示。
- **模型选择 / Model selection**：会话只接受 Provider catalog 中可用的模型；Qoder 模型发现
  使用有界超时，发现失败时只展示受控的静态建议。
- **运行观测 / Runtime visibility**：增加 Run 列表慢请求日志与内存回收状态，并延长 Core 冷启动
  健康检查窗口，使部署失败原因更清晰。

## 升级注意 / Upgrade notice

- 本版本没有数据库 schema migration，也不执行数据维护；持久化合同与 `v0.2.2` 兼容。
- 升级前仍应按常规流程备份并验证 `runner.db`，并阅读
  [release, upgrade, and rollback](../runbooks/release-upgrade-rollback.md)。
- 发布资产继续包含并校验固定版本的 Claude SDK、Qoder CLI runtime 与 Pi policy extension。

This release has no database schema migration or data-maintenance step and remains storage-compatible
with `v0.2.2`. Back up and verify `runner.db` before upgrading and review the release runbook.
