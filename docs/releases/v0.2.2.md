# Xuanwu v0.2.2

玄武 `v0.2.2` 完善了 Qoder Code Agent 接入与统一执行策略，并继续收紧调度、Session、
审批和 managed executor 生命周期边界。

Xuanwu `v0.2.2` completes the Qoder Code Agent integration and unifies execution policy
handling while tightening scheduler, session, approval, and managed-executor lifecycle behavior.

## 重点更新 / Highlights

- **Qoder integration**：支持 Session 创建、恢复、历史读取、事件转译、用量展示、显式
  allow/deny、workspace containment 与精确中断；release 资产包含冻结的 Qoder CLI runtime
  及其 policies。
- **Unified execution policy**：Codex、Claude、Pi 和 Qoder 统一解析 sandbox、approval 与
  provider-specific permission，策略可持久化并在 Session 和 Run 中保持一致。
- **Runtime reliability**：优化调度索引、事件维护、Project 查询和 Provider Session 生命周期，
  限制 Codex 进程刷新洪峰并修复首次 release 目录升级。
- **Lifecycle safety**：managed executor 不能直接改写 Issue 生命周期；PI 验收、通知、重试和
  最终执行结果使用更明确的合同。
- **Claude local auth**：Claude SDK 可以安全复用本机已有登录，同时保持环境变量 allowlist 和
  secret 隔离。

## Provider 验收状态 / Provider acceptance status

- **Codex**：继续作为已完成主链真实验收的稳定 Provider。
- **Qoder**：source runtime 下的真实 read-only、Session resume、Runner 重启恢复、显式
  allow/deny、并发和精确 interrupt 已取得证据；release 安装布局和完整失败矩阵未全部完成真实验收，
  因此仍为 `preview`。
- **Claude / Pi**：本版本加强了执行策略与 Session 合同，但不把自动化覆盖表述为新的真实账号
  端到端验收。

Codex remains the stable provider with primary-path live acceptance. Qoder has bounded
real-account evidence on the source runtime but remains `preview`; release-layout and complete
failure-matrix live acceptance are still incomplete. Automated coverage for Claude and Pi is not
presented as new real-account end-to-end acceptance.

## 升级注意 / Upgrade notice

- 升级前备份 `runner.db`，并阅读
  [release, upgrade, and rollback](../runbooks/release-upgrade-rollback.md)。
- 本版本包含数据库迁移 `078`–`080`，用于内置 Qoder profile、调度索引和执行策略持久化；
  不应使用旧 runtime 直接打开已完成破坏性维护的数据副本。
- Release 安装会校验 Qoder CLI 版本与 runtime policies，资产不完整时将 fail closed。

Back up `runner.db` before upgrading and review the release upgrade/rollback runbook. This release
includes migrations `078`–`080` for the built-in Qoder profile, scheduler indexes, and execution
policy persistence. Release installation validates the pinned Qoder CLI and runtime policies and
fails closed when assets are incomplete.
