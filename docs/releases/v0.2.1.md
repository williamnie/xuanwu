# Xuanwu v0.2.1

玄武 `v0.2.1` 完成了 Code Agent Provider 核心泛化与 Xuanwu 命名收口，并改善了
Project、Work、Session 和 Settings 中的执行器选择、会话恢复与运行反馈。

Xuanwu `v0.2.1` generalizes the Code Agent Provider core, completes the Xuanwu naming
migration, and improves executor selection, session recovery, and run feedback across Projects,
Work, Sessions, and Settings.

## 重点更新 / Highlights

- **Provider-neutral core**：引入 registry、manifest、动态 provider catalog、统一生命周期与
  conformance harness；Codex、Claude、Pi 和 Qoder adapter 进入同一套执行合同。
- **Code Agent 管理**：新增 Code Agents 管理界面，只有启用且 ready 的执行器会进入
  Project、Work、Session 与 Agent Profile 选择器。
- **Session reliability**：修复 Provider Session 路由、历史会话读取与恢复、消息顺序、发送反馈、
  草稿保留和运行中控件。
- **Remote access token**：补全首次 token 生成、浏览器连接、服务端保护和安全轮换链路。
- **Xuanwu naming migration**：Release 资产、二进制、CLI、环境变量、Skill、服务名与默认状态目录
  全部统一为 Xuanwu。

## Provider 验收状态 / Provider acceptance status

- **Codex**：已完成真实执行、Session、恢复、中断与交付主链验收。
- **Claude / Claude Code**：已有实现和自动化覆盖，但真实账号端到端链路尚未完成 live acceptance。
- **Pi / Qoder**：adapter 与 conformance 覆盖已合入；不把 fixture 或接口 gate 冒充真实账号端到端验收。

Codex has completed live acceptance for the primary execution path. Claude, Pi, and Qoder have
adapter and automated coverage at different levels, but are not presented as fully live-tested
without real-account end-to-end evidence.

## 升级注意 / Upgrade notice

这是一次包含不兼容命名迁移的 `0.x` 版本：

- Release 资产与命令改为 `xuanwu`、`xuanwu-daemon`、`xuanwu-install`、`xuanwu-update`；
- 环境变量改为 `XUANWU_*`；
- 默认状态目录改为 `~/.local/state/xuanwu`；
- 不提供旧命令、旧环境变量或旧服务名的兼容别名。

This `0.x` release contains a breaking naming migration. Back up `runner.db` before upgrading and
review [release, upgrade, and rollback](../runbooks/release-upgrade-rollback.md). Existing state is
not moved automatically from the previous default directory.
