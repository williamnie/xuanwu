玄武是本地优先、验证优先的 AI Engineering Control Plane。本版本统一了 Work、Run、
Evidence、Handoff、Attention 与 Automation 的产品闭环。

Xuanwu is a local-first, verification-first AI Engineering Control Plane. This release unifies
the Work, Run, Evidence, Handoff, Attention, and Automation loop.

## 重点更新 / Highlights

- **PI-owned semantic acceptance**：Agent 的完成声明不等于 Work 完成；Provider Turn 结束后
  仍保持 `in_progress`，由 Supervisor 根据真实 Session/workspace 事实判断 `done`、`failed`
  或 `needs_user`。Evidence/Handoff 保留为可审计记录，但不再作为所有任务通用的硬门禁。
- **Unified Work and Run control**：统一 Work Ledger、Run/Attempt 生命周期、进度投影、恢复、
  interrupt/retry/resume 与 reviewer loop。
- **Xuanwu Supervisor**：支持有界工作分解、项目上下文、Workflow、Attention、Approval、
  Standing Orders、Heartbeat 与自动恢复预算。
- **Codex and Claude**：Codex 保持完整 Provider 能力并已完成真实链路测试；Claude 已实现
  Anthropic Agent SDK 与显式 CLI fallback，并保留真实 Provider/Attempt 归属，但在本说明更新时
  尚未完成真实账号端到端验收，状态为 preview / not live-tested。
- **Safer local operations**：Release 安装将 Web Gateway、Runner Core 与 Agentic Worker 隔离，
  增加 daemon doctor、备份/恢复、升级/回滚审计；仓库公开后启用 GitHub artifact attestations。
- **Public release readiness**：GitHub 仓库统一为 `xuanwu`，新增中英文 README、贡献指南、
  安全策略和准确的 source-available 许可说明。

## 兼容与升级 / Compatibility and upgrade

- GitHub repository: `williamnie/xuanwu`
- Product name: `Xuanwu / 玄武`
- Binary and CLI: `xuanwu`
- Environment variables: `XUANWU_*`
- Default state path: `~/.local/state/xuanwu`
- Legacy Issues/Sessions compatibility remains observable through the `v0.3.x` window.

安装前请阅读 [发布、升级与回滚](../runbooks/release-upgrade-rollback.md)；重要数据先完成备份与
恢复演练。Before installing, review the [release, upgrade, and rollback runbook](../runbooks/release-upgrade-rollback.md)
and test a backup restore for important state.
